# temporal-binding-analysis

Analysis code and experiment scripts for an MA thesis investigating the cognitive and predictive mechanisms underlying **temporal binding** — the perceived compression of time between a voluntary action and its sensory outcome.

**Department:** Cognitive Science  
**Thesis title:** *Sensorimotor Mechanisms of Time Perception: Investigating Temporal Binding Effect Through Predictive Mechanisms*

---

## Overview

Temporal binding refers to the finding that the interval between a voluntary action and its effect is subjectively compressed relative to intervals not initiated by voluntary action (Haggard et al., 2002). This thesis tests whether **temporal control** (the capacity to cause an outcome) is sufficient to produce binding, and whether **identity prediction** and **temporal prediction** modulate the binding magnitude or reaction times independently.

Three experiments used an **interval reproduction paradigm**: participants held the space bar for the perceived duration of a preceding interval. An acquisition phase preceded a test phase within each block, allowing manipulation of what participants could learn about timing and stimulus identity.

### Experiment structure

Each experiment comprised **8 blocks** in the same order:

| Block | Code    | Condition Type     | Acquisition | Test  |
|-------|---------|--------------------|-------------|-------|
| 1     | IC-FF   | Identity Control   | Fixed       | Fixed |
| 2     | IC-RF   | Identity Control   | Random      | Fixed |
| 3     | IP-FF   | Identity Prediction| Fixed       | Fixed |
| 4     | IP-RF   | Identity Prediction| Random      | Fixed |
| 5     | TC-RR   | Temporal Control   | Random      | Random|
| 6     | TC-FR   | Temporal Control   | Fixed       | Random|
| 7     | TC-RF   | Temporal Control   | Random      | Fixed |
| 8     | TC-FF   | Temporal Control   | Fixed       | Fixed |

**Condition types:**
- **IC (Identity Control):** Active action, no identity prediction possible (outcomes randomised)
- **IP (Identity Prediction):** Passive trigger, identity prediction possible (tones mapped to colours)
- **TC (Temporal Control):** Active action, no identity prediction; test phase timing manipulated

### Key differences across experiments

| Feature | Exp 1 (n=10, pilot) | Exp 2 (n=41) | Exp 3 (n=41) |
|---------|---------------------|--------------|--------------|
| Fixed IEI | 550 ms | 650 ms | 650 ms |
| Random IEI | 0–1100 ms | 150–1150 ms | 150–1150 ms |
| Acquisition trials | 50 | 30 (+20% catch) | 30 (+20% catch) |
| Test congruency | Uncontrolled | 50% congruent | 80% congruent |
| RT collection | No | Yes | Yes |
| Exclusion criterion | — | Catch accuracy < 80% | Catch accuracy < 80% |

## Analysis pipeline

All statistical analyses use linear mixed-effects models (LMMs) fit with `lme4`. The pipeline is consistent across all experiments:

1. **Data cleaning** — convert durations to milliseconds, apply RT exclusion window (100–2000 ms), derive `RATIO`, `log_RATIO`, and `RRE`
2. **Catch trial exclusion** (Exp 2 & 3) — participants with catch trial accuracy below 80% excluded
3. **Sum contrasts** applied to all categorical predictors via `contr.sum()`
4. **Model selection** — forward and backward LRT comparison (ML estimation) to identify the best fixed- and random-effects structure
5. **Confirmatory test** — `afex::mixed()` with `method = "LRT"` on the winning model
6. **Outlier trimming** — ±2.5 SD on winning model residuals, model re-run on trimmed data
7. **Assumption checks** — VIF, ACF, residual histogram, Q-Q plot, fitted vs. residual plot

### Comparisons per experiment

| Analysis | Subset | Predictors | DV |
|----------|--------|------------|----|
| MC | TC vs. IC | cond.type × acq.time | RATIO (Exp 2) / log_RATIO (Exp 3) |
| CP | TC vs. IP | cond.type × acq.time | RATIO (Exp 2) / log_RATIO (Exp 3) |
| mvsp | IC vs. IP | cond.type × acq.time × is_valid | RATIO (Exp 2) / log_RATIO (Exp 3) |
| t_control | TC blocks only | acq.time × test.time | log_RATIO (all experiments) |
| RT (Exp 2 & 3) | IC vs. IP | cond.type × acq.time × is_valid | log_space_RT |

## Dependencies

### R

```r
install.packages(c("here", "tidyverse", "lme4", "afex", "car"))
```

Tested on R ≥ 4.2. Set working directory to repo root before running — all paths use `here::here()`.

### Python (PsychoPy)

- PsychoPy ≥ 2022.2
- `psychtoolbox` (PTB audio backend, required for Identity Prediction scripts)

Install PsychoPy via the standalone installer: https://www.psychopy.org/download.html

## Reproducing the analyses

```r
# From repo root in R:
source("scripts/r/exp1_analysis_FINAL.R")
source("scripts/r/exp2_ratio_analysis.R")
source("scripts/r/exp2_rt_analysis.R")
source("scripts/r/exp3_ratio_analysis.R")
source("scripts/r/exp3_rt_analysis.R")
```

Figures are saved to `figures/` automatically at 300 dpi.
